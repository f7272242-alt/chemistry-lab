# آزمایشگاه شیمی — نسخهٔ بدون آزمایشگاه سه‌بعدی، آزمایشگاه مجازی و مأموریت کات کبود

## تغییرات این نسخه

- حذف کامل تب و کامپوننت آزمایشگاه سه‌بعدی
- حذف تب و شبیه‌ساز آزمایشگاه مجازی قدیمی
- حذف کامل مأموریت کات کبود و مراحل/جایزهٔ مربوط به آن
- حفظ جدول تناوبی، مولکول‌ساز، مرکز اسید و باز، دانشنامه، آزمون، دفترچه و دستیار هوش مصنوعی
- به‌روزرسانی دانش ارسالی به AI تا فقط قابلیت‌های موجود در این نسخه را توصیف کند
- اضافه‌شدن حالت استقرار آنلاین: سرور Node.js اکنون می‌تواند هم API هوش مصنوعی و هم نسخهٔ build شدهٔ سایت را از یک دامنه ارائه کند

## اجرای محلی در ویندوز

1. ZIP را از حالت فشرده خارج کن.
2. Node.js نسخهٔ LTS را نصب کن: https://nodejs.org/
3. از `.env.example` یک کپی با نام `.env` بساز.
4. فایل `.env` را باز کن و یک کلید API جدید وارد کن:

```env
AI_API_KEY=کلید_جدید_تو
AI_BASE_URL=https://api.openai.com/v1
AI_MODEL=gpt-4o-mini
AI_SERVER_PORT=3001
```

5. روی `start.bat` دوبار کلیک کن. پنجرهٔ سرور AI و پنجرهٔ Vite باز می‌شوند.
6. نشانی‌ای را که Vite نشان می‌دهد در مرورگر باز کن.

اگر کلیدی قبلاً در چت یا کد عمومی قرار گرفته، آن را باطل کن و کلید تازه بساز. کلید را هرگز داخل فایل‌های `src` یا کد مرورگر قرار نده.

## آنلاین‌کردن سایت و دستیار هوش مصنوعی با Render

این پروژه برای استقرار یک‌سرویسی روی Render آماده شده است. در این حالت، همان سرور هم فایل‌های سایت و هم مسیرهای `/api/...` را ارائه می‌کند؛ بنابراین نیازی به آدرس جداگانه برای API نیست.

1. پروژه را از ZIP خارج کن.
2. پوشهٔ پروژه را در یک مخزن خصوصی GitHub قرار بده. فایل `.env` را آپلود نکن؛ `.gitignore` آن را نادیده می‌گیرد.
3. وارد https://render.com شو و حساب بساز.
4. در داشبورد Render گزینهٔ **New + → Blueprint** را انتخاب و مخزن GitHub را متصل کن.
5. Render فایل `render.yaml` را می‌خواند و سرویس را می‌سازد.
6. در تنظیمات Environment سرویس، مقدار `AI_API_KEY` را به‌عنوان Secret وارد کن. کلید را در کد یا فایل عمومی قرار نده.
7. مطمئن شو `AI_BASE_URL` و `AI_MODEL` با سرویس‌دهندهٔ API تو مطابقت دارند.
8. پس از Deploy، نشانی HTTPS ساخته‌شده توسط Render را باز کن. برای بررسی سرور، مسیر `/api/health` را باز کن؛ باید JSON با `ok: true` ببینی.

اگر سرویس‌دهنده‌ات OpenAI نیست، `AI_BASE_URL` را مطابق مستندات همان ارائه‌دهنده تنظیم کن؛ باید از قالب OpenAI-compatible Chat Completions پشتیبانی کند. مدل `AI_MODEL` نیز باید در حساب آن سرویس در دسترس باشد.

## «آموزش» و آشنایی هوش مصنوعی با محتوای سایت چگونه کار می‌کند؟

این نسخه مدل پایه را دوباره آموزش نمی‌دهد یا وزن‌های آن را تغییر نمی‌دهد. به‌جای آن، در هر درخواست یک بستهٔ دانش از محتوای واقعی سایت به مدل فرستاده می‌شود. این روش برای پروژهٔ آموزشی کوچک، ساده‌تر و قابل به‌روزرسانی‌تر است.

بستهٔ دانش شامل مواردی مانند این‌هاست:
- رکوردهای کامل عناصر و مشخص‌بودن خانه‌های جدول که فقط placeholder هستند
- ترکیبات ثبت‌شده
- فهرست مواد، تجهیزات و واکنش‌های مرکز اسید و باز
- درس‌ها و پرسش‌های دانشنامه
- اطلاعاتی که مدیر/کاربر پس از بررسی و تأیید به دانش سایت اضافه کرده است

در پنل دستیار:
1. سؤال خود را بپرس.
2. برای یافتن کمبودها، «بررسی کمبودهای دانشنامه» را بزن.
3. منبع و محتوای پیشنهادشده را بررسی کن.
4. فقط موارد معتبر را با دکمهٔ «افزودن» تأیید کن.

اطلاعات تأییدشده در `data/approved-knowledge.json` روی سرور ذخیره می‌شوند و در درخواست‌های بعدی به هوش مصنوعی فرستاده خواهند شد. از آنجا که این فایل روی دیسک سرویس میزبانی ذخیره می‌شود، در سرویس‌های دارای فایل‌سیستم موقت ممکن است با استقرار مجدد یا راه‌اندازی مجدد پاک شود؛ برای استفادهٔ دائمی و چندکاربره، یک پایگاه دادهٔ پایدار متصل کن.

## نکات آنلاین و هزینه

- برای پاسخ‌گویی آنلاین، هم سایت باید میزبانی شود و هم سرور Node.js و API key باید تنظیم شده باشند.
- خود سرویس‌دهندهٔ مدل ممکن است بابت درخواست‌ها هزینه بگیرد؛ محدودیت مصرف و بودجهٔ حساب API را تنظیم کن.
- پلن رایگان میزبانی ممکن است پس از مدتی بی‌استفاده‌ماندن سرویس را متوقف کند و اولین درخواست بعدی دیرتر پاسخ بگیرد.
- endpoint عمومی AI در این نسخه محدودیت سادهٔ تعداد درخواست دارد؛ برای انتشار گسترده، احراز هویت، سهمیه‌بندی کاربران و پایگاه دادهٔ پایدار اضافه کن.

## دقت علمی و ایمنی

- این AI مدل پایه را fine-tune نمی‌کند؛ از اطلاعات سایت به‌عنوان زمینهٔ پاسخ استفاده می‌کند.
- پیشنهادهای دانشنامه تا زمان تأیید به محتوای تأییدشده اضافه نمی‌شوند.
- پاسخ‌های مهم را با منابع معتبر مانند PubChem، NIST Chemistry WebBook و IUPAC بررسی کن.
- دربارهٔ مواد بسیار خطرناک، گازهای سمی، مواد منفجره و واکنش‌های آسیب‌زا فقط توضیح مفهومی و شبیه‌سازی غیرعملیاتی ارائه می‌شود.
